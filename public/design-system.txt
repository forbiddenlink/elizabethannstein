# elizabethannstein.com — Design System (AI-readable index)

> Machine-readable token + component contract for AI coding agents (Claude, Cursor, v0).
> Recruiter-facing portfolio. "Arresting + credible." Pure-dark achromatic base; color ONLY via the galaxy palette (6 project categories = 6 semantic colors).
> When generating UI: pick ONLY from the named tokens below. Never emit ad-hoc hex/px.
> Token SoT = src/app/globals.css (:root). Philosophy = .impeccable.md.

Site: https://elizabethannstein.com
Stack: Next.js 16.2, React 19.2, Tailwind CSS v4 (zero-config, @import "tailwindcss"; tokens in :root NOT @theme), Three.js + @react-three/fiber (3D galaxy), GSAP, Framer Motion. Source in src/.
NOT shadcn — buttons/cards are hand-rolled CSS classes in globals.css (.btn, .btn-primary/-secondary/-ghost, .btn-galaxy-*, .glass-card, .glass-panel). No cva/radix.
Colors are hex + RGB triples (no OKLCH/HSL).

## Fonts (next/font/google)
- Body / sans: Space Grotesk — --font-space-grotesk (weights 300-700)
- Display / editorial serif: Fraunces — --font-display (variable, preloaded)
- Code / mono: JetBrains Mono — --font-jetbrains-mono (400-700)

## Color tokens (closed set — src/app/globals.css)
Base: --background #000000, --color-surface #0a0a0a, --color-elevated #111111
Text: --color-text-primary #f0f0f0, --color-text-secondary #999999, --color-text-tertiary #666666
Accent: --color-accent #f0f0f0 (achromatic — accent is NOT a color here)
Galaxy palette (SEMANTIC LAW — 6 categories, each its own hue + RGB variant, never mix across categories):
  --color-galaxy-enterprise #ff6b35, --color-galaxy-ai #00d9ff, --color-galaxy-fullstack #b47eff,
  --color-galaxy-devtools #06ffa5, --color-galaxy-creative #ff4d94, --color-galaxy-experimental #ffb800
UI accents (purple/indigo/blue/pink) + semantic success/warning/error/info: RGB triples in :root.
Use when (grep of src/; paths from repo root). Two scopes: the :root tokens above serve /explore and src/components/3d; content pages use the .editorial scope (--le-* in src/styles/editorial.css:19-160, see Known debt).
- --color-surface: panel behind overlay UI (src/components/ui/GalaxyGuide.tsx:140). --color-elevated: one step lighter than surface, for nested chips (use when: UNCLEAR, ask Liz, 3 uses). Choose surface for the panel, elevated only inside a surface panel.
- --color-text-primary/-secondary/-tertiary: default / supporting / least-important copy on the dark base (src/components/ui/LoadingProgress.tsx:78). --color-border (default hairline) vs --color-border-subtle (use when: UNCLEAR, ask Liz, no consumer).
- --color-accent / -hover / -text: the achromatic button fill, its hover, and the label on it (.btn-primary).
- --color-accent-purple: purple tint on glass hover (src/app/globals.css:305). --color-accent-indigo/-blue/-pink and --color-success/-warning/-error/-info: use when: UNCLEAR, ask Liz (no consumer found in src/).
- --color-galaxy-<category> and -rgb: .btn-galaxy-<category> (src/app/globals.css:861) and 3D project nodes (src/lib/galaxyData.ts:12). Use the hex form for solid fills and the -rgb form inside rgba() for opacity.
- Editorial scope (content pages): --le-paper (page ground) / -2 (card or band) / -3 (pressed or darkest surface, editorial.css:648). --le-ink body and headings, --le-ink-2 supporting text, --le-muted captions (must clear AA on --le-paper-3). --le-rule hairline, --le-rule-strong emphasis rule (editorial.css:284). --le-accent fills and focus outline (editorial.css:787,845); --le-accent-ink accent text and links (editorial.css:179); --le-accent-wash soft accent background (editorial.css:60,399). --le-live status-OK dot (editorial.css:294), --le-down failure state (editorial.css:628). --le-cat-* category dots, not fills. --le-rule-2, --le-tint, --le-live-ink: use when: UNCLEAR, ask Liz (no consumer found).

## Scale tokens
- Type (1.25 ratio): --text-xs 0.75rem … --text-6xl 3.75rem (+ line-heights, weights)
- Spacing (4px base): --space-1 … --space-32 (+ section / card-padding aliases)
- Radius: --radius-sm/md/lg/xl/2xl = 4/8/12/16/24px (xl + 2xl ARE defined)
- Motion: duration 50-400ms tokens, 7 named eases
- Z-index: 10-level scale
- SHADOWS: none — "elevation via color shift + border only" (glass is the only elevation model). Do NOT add shadow-*.
Use when: --ease-out-expo (default entrances), --ease-default and --ease-image-hover are the only eases with consumers (src/app/globals.css). Type, spacing, opacity, z-index, duration, --ease-magnetic/-in-out-cubic/-out-quart/-out-quint, --btn-radius/--card-radius/--input-radius/--badge-radius, --btn-transition: use when: UNCLEAR, ask Liz (no var() consumer found in src/). --radius-xl/-2xl/-full have a few consumers.

## Hard rules (.impeccable.md)
- Named tokens only. Galaxy colors are semantic law — never mixed across categories.
- Glass is the ONLY elevation model (no shadows). 44px touch targets non-negotiable.
- Anti-references (banned): generic AI-SaaS gradient-blob-on-white templates, gimmicky over-designed noise, "resume-in-a-box."
